Privacy Policy

Last updated: February 2026

Welcome to BookNest. This Privacy Policy outlines how user details, registered book entries, and book favorites are stored and managed. BookNest is a full-stack engineering college project developed using Spring Boot, Spring JDBC, and MySQL.

Information We Collect

When you use BookNest, you may provide your name, email address, and a password for account registration. You may also submit book information (title, author, ISBN, category, price, availability, and description) through the book registration form.

How Information Is Used

User account details are used exclusively to manage authentication and associate your favorites list with your user ID. Registered book records are stored to expand the visible catalog for browsing and demonstration purposes.

Database Storage

Unlike static mock websites, BookNest communicates with a real MySQL relational database (booknest_db) through Spring Boot REST APIs using JdbcTemplate:

  • Users Table: Stores full name, email, and password for demo student accounts.
  • Books Table: Stores catalog books, categories, pricing, and descriptions.
  • Favorites Table: Links user accounts to their saved book records using relational foreign keys.

Cookies and Browser Storage

BookNest does not use commercial tracking cookies or advertisement trackers. A small session key in browser localStorage is used strictly to retain the active user login state during your visit.

Third-Party Services

BookNest loads standard CSS and JavaScript frameworks from the Bootstrap 5 public Content Delivery Network (CDN). No other third-party analytics or surveillance services are included.

Data Security

This application implements parameterized SQL queries via JdbcTemplate to prevent SQL injection vulnerabilities. Because this is an educational project running on a local development environment, please do not submit real passwords or sensitive personal documents.

Children's Privacy

BookNest is an educational academic demonstration and does not deliberately gather personal identification from children under the age of 13.

Changes to Policy

Any future adjustments or improvements made to the project will be recorded directly on this policy page.
